This document establishes the functional boundary for the MVP and outlines the prioritized developer roadmap for incoming engineers.

## In-Scope vs. Out-of-Scope Boundaries

### In-Scope (MVP Capabilities)
* **PDF Document Ingestion:** Parsing standardized GeM bid documents, PSU tender circulars, Additional Terms & Conditions (ATCs up to 400 pages), and BOQ line items.
* **Two-Layer Extraction:** Deterministic Layer 1 regex table parsing backed by Layer 2 scoped LLM fallback via Anthropic Claude (Haiku 4.5 and Sonnet 5.5).
* **Form Auto-Hydration & Visual Confidence Badges:** Pre-populating the React `InfoSheetForm` with Green (verified), Amber (AI resolved with reasoning tooltips), and Red (missing) badges.
* **Bidding Requirements Checklist:** AI extraction of mandatory compliance certificates (balance sheets, experience certificates, MAF, MSE declarations) with exact page references.
* **Annexure Template Generation:** Exporting pre-filled Microsoft Word (`.docx`) forms.
* **Cost & Token Accounting:** Persisting token counts, cache hits, and USD expenditures in PostgreSQL `claude_token_usage`.
* **Deduplication & Multi-Tier Caching:** SHA-256 PDF hashing preventing redundant token burn on unmodified tenders.

### Out-of-Scope (Non-Goals for MVP)
* **Automatic Bid Submission on GeM / CPP Portal:** Legally out-of-scope. Indian public procurement portals require a physical USB cryptographic dongle (Class 3 Digital Signature Certificate or DSC) and Aadhaar/OTP verification. Final bid submission must remain strictly human-in-the-loop.
* **Automated Price Quoting / Profit Margin Calculation:** Costing sheets and financial bidding rates are computed manually by company estimators using vendor RFQs.
* **Multi-Lingual Vernacular OCR:** State tenders published exclusively in regional Indian languages (e.g., Hindi, Tamil, Marathi) are out-of-scope; English-language procurement documents are strictly targeted.
* **Automated Pre-Bid Query Submission:** Drafting clarification questions is assisted, but submitting portal tickets remains manual.
