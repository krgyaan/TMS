## Microservice Architecture

**VolksAI** (`volksAi/`) is a high-throughput Python FastAPI microservice dedicated to reading heterogeneous Indian procurement documents, extracting tables deterministically, resolving complex legal clauses via Anthropic Claude, and building Word (`.docx`) annexure packages.

```mermaid
graph TD
    Client[NestJS API / BullMQ Worker] -->|HTTP Multipart /extract| Router[extract.py Router]
    
    subgraph Ingestion & Pre-processing
        Router --> Ingest[pdf_parent_ingest.py]
        Ingest --> PyMuPDF[PyMuPDF / fitz & pdfplumber]
        Ingest --> Classifier[document_classifier.py]
        Ingest --> Links[pdf_link_extractor.py]
        Ingest --> OCR[PaddleOCR Deep Learning Engine]
    end
    
    subgraph Layer 1: Deterministic Engine (0 Tokens)
        PyMuPDF --> TenderMapper[tender_mapper.py 242KB]
        TenderMapper --> FieldAliases[gem_field_aliases.py & gail_clause_aliases.py]
        TenderMapper --> Normalizer[normalizer.py]
        TenderMapper --> L1Match[High Confidence Fields]
    end
    
    subgraph Layer 2: Scoped LLM Engine
        TenderMapper -->|Missing / Ambiguous| LLMResolver[llm_field_resolver.py 111KB]
        LLMResolver --> Scope[extract_scoped_context]
        Scope --> Role1[Role 1: Claude Haiku 4.5 Tool Use]
        Scope --> Role2[Role 2: Claude Sonnet 5.5 Tool Use]
    end

    subgraph Document Compliance & Annexures
        Ingest --> BiddingReq[bidding_requirements_resolver.py - Role 3 Sonnet 5]
        Ingest --> AnnexureRes[annexure_resolver.py - Role 4 Sonnet 5]
        AnnexureRes --> DocxBuilder[annexure_docx_builder.py - Letterhead .docx Builder]
    end
    
    L1Match --> FieldMapper[tms_field_mapper.py]
    Role1 --> FieldMapper
    Role2 --> FieldMapper
    FieldMapper --> Output[Structured NestJS camelCase DTO]
```

## Microservice Subtree Walkthrough

```
volksAi/
├── app/
│   ├── main.py                     # FastAPI entrypoint, middleware, CORS, lifespan startup
│   ├── routers/
│   │   ├── extract.py              # POST /extract (Tender PDF ingestion & field extraction)
│   │   ├── bidding_requirements.py # POST /analyze-bidding-requirements (Checklists)
│   │   ├── annexures.py            # POST /annexures/download-docx
│   │   ├── classify.py             # POST /classify-documents
│   │   └── health.py               # GET /health
│   ├── services/
│   │   ├── pdf_parent_ingest.py    # PyMuPDF/pdfplumber parser and PaddleOCR coordinator
│   │   ├── pdf_link_extractor.py   # Extracts external tender document hyperlinks
│   │   ├── document_classifier.py  # Deterministic 0-100 score document classifier
│   │   ├── tender_mapper.py        # Layer 1 deterministic regex mapping (242 KB)
│   │   ├── gem_field_aliases.py    # GeM table header aliases
│   │   ├── gail_clause_aliases.py  # PSU custom contract aliases
│   │   ├── normalizer.py           # Money, percentage, and date-time normalizers
│   │   ├── field_extractor.py      # Spatial table and text parser
│   │   ├── llm_field_resolver.py   # Layer 2 Claude resolver (Role 1 & Role 2) (111 KB)
│   │   ├── bidding_requirements_resolver.py # Role 3 compliance document analyzer
│   │   ├── annexure_resolver.py    # Role 4 annexure format identifier
│   │   ├── annexure_docx_builder.py# Deterministic .docx builder with company letterhead
│   │   └── tms_field_mapper.py     # Maps Python outputs to camelCase NestJS DTOs
│   └── core/
│       ├── config.py               # Environment configuration settings
│       └── logging.py              # Rotating file logger writing to logs/volksai.log
├── scratch/                        # Diagnostic scripts and test fixtures
├── Dockerfile                      # Container definition with PyMuPDF and PaddleOCR
└── requirements.txt                # Python dependencies
```
